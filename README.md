Task Management · Hail Region Municipality

A classic, data-focused task management portal designed to help departments coordinate work, track deadlines, manage priorities, and organize follow-up reminders.

Overview

The platform provides a structured workspace for managing departmental tasks through a clean, responsive interface with dedicated dashboards, task management, calendars, departments, and reminders.

Key Features

* 🔐 Role-based authentication for different user types
* 📊 Dashboard with task metrics, deadlines, and reminders
* 📋 Task creation and status management
* 📅 Calendar view for tracking departmental deadlines
* 🏢 Department directory with workload information
* 🔔 Reminder management and follow-up tracking
* 📱 Responsive interface for desktop and smaller screens

Tech Stack

* HTML
* CSS
* JavaScript
* PHP
* MySQL
